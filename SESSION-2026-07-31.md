# Session 30 — portalCore gate: connection-level client identity (2026-07-31)

Goal-2 blocker characterization. Full writeup: `GOAL2.md` "Session 30" section.

## TL;DR
`portal200001` ("版本已停止使用") is returned to ANY non-app client **before the request body is
parsed** (garbage body → same response). The app's own request (extracted from its heap
`service_name:"portal"` DoHttpSec log) was replayed byte-exact — still rejected. The app's TLS is a
bundled Ranger-native minimal TLS 1.2 stack; the server negotiates **0xcca9 (TLS 1.3 cipher) in a
TLS 1.2 handshake** with the app, 0xc02b with everyone else. A Go `utls` client replicating the app's
exact ClientHello gets the 0xcca9 negotiation but still `portal200001` — the residual diff is in the
Ranger native HTTP/2 layer (SETTINGS/header framing) or a native session token.
